# Home Assistant Apps by rpimeekle

[![Add repository to Home Assistant][repo-badge]][repo-link]
[![Build](https://github.com/rpimeekle/ha-apps/actions/workflows/build.yaml/badge.svg)](https://github.com/rpimeekle/ha-apps/actions/workflows/build.yaml)

Lightweight self-hosted tools packaged as Home Assistant apps. Add this
repository once and every app below appears in your App Store.

## Install

1. Click the button above, or go to **Settings → Apps → App store → ⋮ →
   Repositories** and add `https://github.com/rpimeekle/ha-apps`.
2. Pick an app from the new section in the store, install and start it.
