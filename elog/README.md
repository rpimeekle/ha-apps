# ELOG

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

[PSI ELOG](https://elog.psi.ch/elog/), a small, self-contained web-based
electronic logbook, right in your Home Assistant sidebar.

- ELOG built from source, no database
- Opens in the sidebar through Home Assistant ingress, with optional direct
  port 8080
- Threaded entries, attributes, attachments and full-text search
- Logbooks, login and self-registration configurable from the app options
- Logbook data stored in `/data`, so it is included in backups

See the **Documentation** tab for setup details.
